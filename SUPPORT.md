# Getting Support for Athena AI

Welcome to **Athena AI (Robinhood Chain Edition)**! Here are the official resources and channels to get help, report issues, or connect with the community.

---

## 💬 Interactive Support Channels

- **Discord Parthenon Command Center**: Join our Discord server and navigate to `#athena-control-room` for natural language chat, setup assistance, and strategy configuration.
- **Telegram Notification Bridge**: Follow real-time signal broadcasts and status alerts.
- **Terminal TUI Diagnostics**: Run `athena doctor` or `athena terminal` in your terminal for real-time diagnostic checks on API keys, RPC connections, and wallet configuration.

---

## 🐛 Bug Reports & Feature Requests

If you encounter unexpected behavior, RPC connection issues, or have ideas for new sub-agents or Web3 features:

1. **Check Documentation**: Review our [README.md](file:///c:/Jurnalexa/Crypto/Athena%20AI%20%28Robinhood%20Chain%29/README.md) and [AGENTS.md](file:///c:/Jurnalexa/Crypto/Athena%20AI%20%28Robinhood%20Chain%29/AGENTS.md).
2. **Search Issues**: Check if your issue has already been reported in the GitHub Issue Tracker.
3. **Submit an Issue**: Provide detailed steps to reproduce, execution mode (`DRY_RUN`, `AUTO_EXECUTE`), Node.js version, and relevant log snippets.
